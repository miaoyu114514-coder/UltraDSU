# UltraDSU 0.2.8 Alpha 13

本次预发布包含 Alpha 11 之后的安装流程、取消、镜像提取和自动清理更新，可直接覆盖同签名 Alpha 版本。

## 更新

- **一键安装**：将“准备镜像”和“安装到槽位”合并为“安装”。Root 模式自动完成准备和写入；无 Root 准备完成后自动展示 ADB 命令，仍需在电脑执行。
- **取消新槽安装**：准备、userdata 分配及分区写入期间，可从进度气泡或通知提出取消。等待系统结束当前操作后清理本次未完成槽，保留准备镜像供重试；不直接杀掉写入进程。提交完成标记、恢复启动选择阶段暂时禁止取消。
- **显示当前分区**：收起和展开的气泡及通知显示“分配 userdata”“写入 system”等阶段，进度条按当前分区或阶段显示。
- **提取已安装分区**：槽编辑页新增“提取”，逐分区导出完整 raw `.img` 到系统文件选择器中的位置，支持进度、取消和传输 SHA-256 校验。直接流式保存，无需额外一整份临时副本；已映射、运行中或待修复的目标拒绝提取。
- **成功后自动清理**：安装或分区替换确认成功后，删除应用内准备副本与安装 ZIP，保留分区清单及容量信息。Root 刷新确认历史槽完整时，也会清理旧副本；失败、取消、未确认提交及待修复任务保留准备文件。
- 清理不涉及原始镜像、原始压缩包、真实 DSU 分区和 userdata 回退备份；拒绝越界路径与符号链接。清理失败保留已安装结果并在刷新时重试。

## 安装与兼容性

版本 `0.2.8-alpha.13` / versionCode `24`，最低 Android 10 / API 29。沿用原发布签名，可覆盖升级；不同签名的 Debug 版不能直接覆盖。

发布证书 SHA-256：`261f796ec575501160e20c3f3e951369180e38f7e4d2bc5e4a1a2350e830c749`。

Root 内置安装和分区提取需要 Android 11+ 的槽接口，内部命名槽仍受 gsid 兼容性限制。Android 10 的 Root 安装准备后交给系统安装器；提交给系统后，进度和取消使用系统 DSU 通知。无 Root 无法确认系统安装完成，不会仅凭“已提交”自动删除准备文件。

userdata 提取结果是**原始加密块镜像**，不能直接浏览，且不包含独立恢复所需的全部密钥和槽元数据，不等同于扩容回退备份。保存位置需有足够空间。

保留数据扩容继续保持实验性，沿用 Alpha 11 的 Android 16+ / arm64、已适配内部槽、F2FS 和加密组合限制。本次没有扩大扩容支持范围，Moto Android 14 仍不支持该扩容工具。

## 验证

- Release 编译和签名检查通过；129 项 JVM 测试中 127 项通过、2 项因 Windows 符号链接权限跳过，无失败或错误；lint 0 错误、25 警告。符号链接保护另在真实 Android 文件系统验证通过。
- 已覆盖安装到 moto razr 2022 / Android 14，在已核验的内部多槽回移 gsid 上测试专用合成槽：自动准备并安装、userdata 分配取消、system 写入取消、raw 提取和取消均通过；导出与原始 64 MiB 输入的 SHA-256 一致。
- 清理后重新导入并替换分区成功，准备副本再次自动清理；取消分配后准备文件仍保留并可复用。原有 dsu、los 槽的容量、启动选择和启用状态与基线一致。
- Root 刷新自动清理 Moto 上历史遗留的约 2.06 GiB 准备副本，应用私有数据降至约 1 MiB，不包含安装包；未改动真实 userdata。
- miuix / Material 3 的合成界面测试通过，收起和展开均可查看当前分区，取消按钮防止重复请求。
- 未启动合成测试系统，未验证所有 ROM、云文件提供方或真实断电；既有扩容测试范围不因本次安装测试而扩大。
