# UltraDSU 0.2.8 Alpha 11

本次公开预发布包含 Alpha 2 之后累积的更新，重点是实验性保留数据扩容、userdata 备份管理及全局任务进度。

## 更新

- F2FS 扩容优先使用加密感知的局部整理，减少全量搬移；保留完整原始备份、独立读回校验、文件系统检查及 FBE 密封记录复核。局部整理无法完成时保留上游全迁移回退路径。
- 扩容整理和扫描阶段显示当前区域的进度条；元数据处理显示阶段名称和动态进度条。备份、校验和恢复仍单独执行，显示的阶段进度不等于整个事务的完成比例。
- 新增客体协作：主系统无法使用跨版本密钥时，可在目标客体中加密采集协作信息，再回到主系统完成预检和扩容。两端需安装相同版本并授权 Root，原槽密钥不重建。
- 新增 userdata 备份管理。当前绑定的 userdata 始终禁止删除，槽未启动时也受保护；可确认清理独立备份，待恢复、记录损坏及状态未知的项目阻止删除。
- 镜像准备、安装、替换和 userdata 操作使用可拖动、展开的全局进度气泡，可跨选项卡和编辑页查看结果。
- 设置新增持久化调试模式、脱敏日志导出及清空、手动 Root 诊断采集；日志保存在本机，不自动上传。
- 修正液态玻璃底栏按压拖动时图标、文字异常放大及部分模糊丢失的问题。
- 构建默认关闭 Gradle 常驻守护进程，Kotlin 编译在构建进程内执行，减少构建结束后的后台 JVM 占用。

## 安装与兼容性

版本 `0.2.8-alpha.11`，versionCode `22`，最低 Android 10 / API 29。沿用之前 Alpha 的发布签名，可覆盖升级；不同签名的 Debug 版不能直接覆盖。

发布证书 SHA-256：`261f796ec575501160e20c3f3e951369180e38f7e4d2bc5e4a1a2350e830c749`。

**保留数据扩容仍为实验功能**，目前要求 Android 16+ / arm64、已适配的内部 DSU 槽、F2FS 及支持的加密组合，并需通过设备预检。硬件封装密钥、加密 ext4 等未适配场景会拒绝。Moto razr 2022 的 Android 14 暂不支持此扩容工具；其他应用功能及备份列表管理不因此要求 Android 16。

完整原始备份需要额外空间。完成扩容后应启动目标系统核对应用与文件，再考虑清理备份；回退会恢复到备份时的状态。“清空并重建 userdata”仍是独立的清除数据操作。
