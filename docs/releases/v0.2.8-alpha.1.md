# UltraDSU 0.2.8 Alpha 1

首个 GitHub Alpha 预发布，基于此前的 0.2.8 开发版本。

## 功能

- Android 10+，miuix / Material 3 即时切换，跟随系统深浅色。
- 可选液态玻璃底栏、实时跟手的选中透镜、选项卡切换及编辑二级页导航动画。
- 自定义 DSU 槽标识、显示名称和 userdata 大小，管理多个系统配置。
- 支持 IMG、ZIP、7z、TAR、GZ、XZ、BZ2，按镜像清单识别单/多分区包。
- Root 模式下扫描系统槽，在编辑页查看实际分区、替换选定镜像及重建 userdata。
- Root 开关持久保存，每次新进程重新核实授权；启动不重复显示授权成功消息。
- 沿用 DSU Sideloader 图标几何，前景/背景分层，并支持莫奈及主题图标。

## 兼容范围与限制

- 命名槽接口从 AOSP Android 11 引入；内部存储独立多槽路径从 Android 15 开放。Android 11–14 的原生 gsid 通常只允许内部默认槽。
- 兼容性还取决于厂商 ROM、动态分区、Bootloader、AVB 和所选 GSI。不能仅靠 Root 权限保证多槽和启动兼容。
- 已按哈希适配的 moto Android 14 实验性 gsid 回移版可放行内部多槽。本次 APK 附件不包含该二进制/模块，也不会自动修改系统 gsid。
- 无 Root 的系统安装器流程可能清理已有 DSU；需要保留多个槽时请核实 Root 内置安装能力。
- userdata 扩容目前是**清空数据后重建**，不支持保留数据直接扩容。
- 不支持 Android sparse、加密/分卷压缩包、RAR 或整机刷机包；不刷 boot、vbmeta、super。
- Android 13+ 使用液态玻璃折射；Android 12 为模糊效果；Android 10/11 使用磨砂回退。
