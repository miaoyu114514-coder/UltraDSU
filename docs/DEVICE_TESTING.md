# 真机验收清单

构建、JVM 测试和 lint 不会在连接设备上安装镜像、删除槽位或重启。以下需要在可恢复、已备份且支持 DSU 的测试设备上人工验收。

| 场景 | 应验证的结果 |
| --- | --- |
| Android 10 | 可启动应用；明确单槽提示，标识固定 dsu，第二个配置被拒绝 |
| Android 11–14 | 区分命名接口和内部路径能力；提示内部仅默认 dsu，命名配置不能提交 Root / ADB 安装 |
| Android 15+ 无 Root | 可创建多配置、设置不同 userdata，安装命令含独立 KEY_DSU_SLOT；系统安装器仍可能先清理已有槽 |
| 缺少系统安装器 | 显示提示，ADB 不可用；核实 Root 多槽接口后内置安装可用 |
| 首次启动、Root 关闭 | 无 su 提示；不展示扫描系统槽、启动、停用、实际槽删除和重启操作 |
| 拒绝 Root | 授权失败消息；保留 Root 开关选择，特权按钮隐藏，可重新检查授权 |
| 允许 Root | 扫描实际槽；错误不被当作空槽列表 |
| 切换 miuix / MD3、重启应用 | 两种真实组件、设置持久；跟随深色；Root 开关持久保存，重启检查授权，授权失效可重试 |
| 镜像格式 | raw ext4 / EROFS 的 img、gz、xz、bz2，以及 ZIP / 7z / TAR 包正常；sparse、损坏包、未知多分区映射明确拒绝 |
| 大镜像准备、旋转、切后台 | 前台服务继续；读取/解包显示已处理 MiB 与 MiB/s；通知取消生效；不要求授予通知才能运行服务 |
| 空间不足、服务终止 | 明确失败；不产生虚假的 PREPARED；残留 partial 可在下次启动清理 |
| ADB 安装 | 系统能读 FileProvider URI；设备出现验证界面与系统安装通知 |
| Root Android 15+ 命名安装 | 先创建独立镜像目录并设置权限和标签；无系统安装器清理步骤；通知显示阶段和写入量；安装后核实 complete，并恢复原启动选择 |
| Root Android 10 安装 | 走系统验证界面；完成前显示已提交；完成刷新后才显示已安装 |
| 两个不同槽 | 使用 Root 内置安装第二个不覆盖第一个；各自 userdata 互相独立 |
| 系统 ADB 流程 | 执行前明确提示会清理当前 DSU，不将它当成保留多槽的安装流程 |
| Root 安装失败 | 取消本次会话，尽量清理新槽；旧槽及其数据保留，清理失败时显示未完成状态 |
| 同名现有槽/半成品 | Root 安装前阻止覆盖；系统安装中禁止切换/删除 |
| 单次启动 | 确认后进入目标 GSI，再重启回主系统 |
| 持续启动、停用 | 持续启动选择生效；停用后重启回主系统 |
| 删除非当前槽 | backing images 回收；当前槽、数据和启动模式不变 |
| 删除当前槽 | 先选中保留槽；其他槽保留，单次/持续模式保持 |
| 删除最后一个槽 | 系统原生 remove 生效，返回无 DSU 状态 |
| 正在运行 DSU | 禁止安装和槽删除，可停用并返回主系统 |
| 厂商非标准布局/SELinux 拒绝 | 显式报错；不递归删除，不自动关闭安全策略 |
| 单分区替换 | 在槽内管理点 system 的替换，选中 raw 或压缩包单镜像；确认后只重建 system，userdata 和其他槽保留 |
| 多分区包替换 | system.img + product.img 同时写入目标槽，先展示清单，不重建 userdata |
| userdata 清空重建 | 读取实际容量，拒绝缩小/同容量；输入槽标识确认后重建更大 userdata，原数据清除，system 等保留 |
| 保留数据扩容 | 在主系统中逐槽预检，先完整备份并校验，再迁移和扩展文件系统；阶段字节进度显示在悬浮气泡，完成后保留备份 |
| 扩容失败 / 进程中断 | 替换后禁止启动和覆盖；保留完整备份，可恢复本应用遗留的 gsid 会话与私有映射，再回退到原尺寸 |
| 扩容备份篡改 / 同名槽密钥改变 | 回退在分配前拒绝，不将旧备份写入新槽；未恢复状态不能清理唯一备份 |
| 扩容完成后 | 解锁 CE，核对 DE / CE 文件校验和、权限、硬链接及应用；确认实际容量增加，并再次重启验证后单独清理备份 |
| 替换失败与恢复 | 保留其他分区和 complete 注册，维护记录阻止启动；重写失败目标成功后解除记录 |
| Root 开关跨进程与设备重启 | 保留用户选择、重新核实权限；拒绝或撤销授权时开关仍开启，特权按钮隐藏，重试可恢复 |

外部扫描到的槽可通过槽内管理尝试读取实际分区容量；读取失败显示未知。通过其他工具进行并发安装/删除不受本应用锁保护，验收时避免同时操作其他 DSU 管理工具。
